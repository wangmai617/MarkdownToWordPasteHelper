# Markdown转Word格式优化粘贴助手

一键将Markdown格式文本转换为Word/WPS兼容格式，解决粘贴排版错乱问题，离线轻量工具。

## 项目介绍

本工具用于解决从AI对话、笔记软件、网页复制Markdown内容到Word时出现的格式混乱问题。
复制Markdown文本后，按下快捷键即可自动转换并粘贴，保留标题、加粗、列表、引用、代码块、表格等完整排版。

- 离线运行，不上传任何数据
- 系统托盘常驻，不占桌面
- 全局热键触发，一键转换粘贴
- 剪贴板监控，自动识别Markdown
- 支持预览、清空剪贴板、自定义快捷键
- 适配 Word2016+ / WPS2019+

## 使用方法

1. 启动程序（无主界面，托盘运行）
2. 复制任意 Markdown 文本
3. 按下快捷键：`Ctrl+Shift+V`
4. 自动转换并粘贴到Word/WPS

支持功能：

- 一键转换粘贴
- 剪贴板Markdown智能检测
- 转换前后内容预览
- 自定义全局快捷键
- 开机自启
- 清空剪贴板
